LINUX · CHIFFREMENT

LUKS — Chiffrement d'un disque/partition Linux

Cas d'usage typique : chiffrer une partition de données (pas la racine) sur un serveur.

1Identifier le disque à chiffrer

lsblk
# Ex : /dev/sdb (disque de données vierge)

sudo fdisk -l /dev/sdb
DANGER — Toute donnée sur le disque cible sera détruite. Vérifier trois fois le chemin (/dev/sdX) avant de continuer.

2Installer cryptsetup

sudo apt install cryptsetup -y

3Formater le disque en LUKS

sudo cryptsetup luksFormat --type luks2 \
  --cipher aes-xts-plain64 --key-size 512 --hash sha512 \
  /dev/sdb

Taper YES en majuscules, puis définir une passphrase forte.

4Ouvrir le conteneur

sudo cryptsetup luksOpen /dev/sdb datavault
# Devient accessible sous /dev/mapper/datavault

5Créer le système de fichiers

sudo mkfs.ext4 /dev/mapper/datavault

6Monter et utiliser

sudo mkdir /mnt/datavault
sudo mount /dev/mapper/datavault /mnt/datavault
sudo chown $USER:$USER /mnt/datavault
df -h | grep datavault

7Fermer proprement

sudo umount /mnt/datavault
sudo cryptsetup luksClose datavault

8Montage automatique au démarrage

# Récupérer l'UUID du disque chiffré (pas du FS)
sudo blkid /dev/sdb
# Ex : UUID="abcd-1234-..."

# /etc/crypttab
sudo nano /etc/crypttab
datavault UUID=abcd-1234-... none luks

# /etc/fstab
sudo nano /etc/fstab
/dev/mapper/datavault /mnt/datavault ext4 defaults 0 2

# Au prochain boot, la passphrase sera demandée en console

9Utiliser un keyfile (déverrouillage auto)

# Créer un keyfile aléatoire 4 Ko
sudo dd if=/dev/urandom of=/root/luks.key bs=1024 count=4
sudo chmod 400 /root/luks.key

# Ajouter le keyfile au conteneur
sudo cryptsetup luksAddKey /dev/sdb /root/luks.key

# Modifier /etc/crypttab pour utiliser le keyfile
datavault UUID=abcd-1234-... /root/luks.key luks

10Sauvegarder le header LUKS

sudo cryptsetup luksHeaderBackup /dev/sdb \
  --header-backup-file /root/luks-header-sdb.img
# À stocker HORS de ce serveur (autre disque, coffre)

11Gérer les passphrases

# Voir les slots utilisés (0-7)
sudo cryptsetup luksDump /dev/sdb | grep "Slot"

# Ajouter une passphrase
sudo cryptsetup luksAddKey /dev/sdb

# Supprimer une passphrase
sudo cryptsetup luksRemoveKey /dev/sdb
PERTE = DONNÉES PERDUES — Sans passphrase ni keyfile ET sans backup du header LUKS, les données sont irrécupérables. Prévoir : passphrase de secours + header sauvegardé hors-site.

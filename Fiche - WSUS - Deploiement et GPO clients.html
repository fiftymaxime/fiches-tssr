WINDOWS SERVER · PATCH MANAGEMENT

WSUS — Serveur de mises à jour interne

Prérequis : Windows Server, 200+ Go d'espace disque (stockage des maj), .NET, IIS.

1Installer le rôle WSUS

Install-WindowsFeature -Name UpdateServices -IncludeManagementTools

2Configuration post-install

# Créer le dossier de stockage
New-Item -ItemType Directory -Path D:\WSUS

# Configurer WSUS pour utiliser ce dossier
cd "C:\Program Files\Update Services\Tools"
.\WsusUtil.exe postinstall CONTENT_DIR=D:\WSUS

3Assistant de configuration initiale

Server Manager → Tools → Windows Server Update Services
L'assistant se lance :
  Upstream server : Microsoft Update
  Proxy           : (si nécessaire)
  Start Connecting → Next
  Languages       : Français, Anglais (uncocher le reste)
  Products        : Windows 10/11, Windows Server 2019/2022, Office (ce dont tu as besoin)
  Classifications : Critical Updates, Security Updates, Definition Updates, Update Rollups
  Sync Schedule   : Daily at 03:00
  ✔ Begin initial synchronization

4Attendre la synchronisation initiale

Console WSUS → Synchronizations
  Compter plusieurs heures (téléchargement des metadata + fichiers)

5Créer des groupes d'ordinateurs

Console WSUS → Computers → All Computers → Add Computer Group

Créer par exemple :
  - Pilotes (5-10 postes de test)
  - Prod-Servers
  - Prod-Postes-Bureautique
  - Prod-Postes-Ateliers

6Approuver des mises à jour (par groupe)

Console WSUS → Updates → All Updates
  Filtre : Approval = Unapproved / Status = Failed or Needed
  Sélectionner les KB → clic droit → Approve
  Pour "Pilotes" : Approved for Install
  Pour "Prod..." : Not Approved (pour l'instant)

7GPO client — pointer les postes vers WSUS

gpmc.msc → nouvelle GPO liée au domaine ou aux OU postes

Configuration ordinateur → Modèles d'administration
  → Composants Windows → Windows Update

Spécifier l'emplacement du service Microsoft Update intranet
  ✔ Activé
    Serveur de mise à jour intranet   : http://wsus.monlab.local:8530
    Serveur intranet de statistiques  : http://wsus.monlab.local:8530

Activer les mises à jour automatiques
  ✔ Activé
    Option 4 : Télécharger et planifier l'installation
    Fréquence : Tous les jours à 03:00

Autoriser l'orientation des cibles côté client
  ✔ Activé
    Nom du groupe cible : Pilotes    # doit correspondre au groupe WSUS

8Forcer un check WSUS côté client

gpupdate /force

# Puis
wuauclt /detectnow /reportnow          # ancien
# Ou (Windows 10/11 / Server 2019+)
usoclient StartInteractiveScan

9Vérifier qu'un poste remonte bien

Console WSUS → Computers → <groupe> → doit apparaître avec :
  - Dernier contact récent
  - Statut de conformité (installées / requises / échouées)

10Nettoyage régulier (indispensable)

Console WSUS → Options → Server Cleanup Wizard
  Cocher :
    ✔ Unused updates and update revisions
    ✔ Computers not contacting the server (30j+)
    ✔ Unneeded update files
    ✔ Expired updates
    ✔ Superseded updates
  Lancer une fois par mois

11Rapports

Console WSUS → Reports
  - Update Status Summary
  - Computer Status Summary
  → Export PDF/Excel pour reporting sécurité
PIÈGE FRÉQUENT — La base WSUSDB (Windows Internal Database) grossit énormément. Faire un Server Cleanup Wizard mensuel + réindexer la base (script WsusDBMaintenance.sql publié par Microsoft) sinon la console devient inutilisable.

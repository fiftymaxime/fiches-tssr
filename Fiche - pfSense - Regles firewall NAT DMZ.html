PARE-FEU · PFSENSE

pfSense — Règles firewall, NAT et DMZ

Config initiale (console série ou vGA)

1Assigner les interfaces

Menu console → 1 Assign Interfaces
  WAN → em0
  LAN → em1
  OPT1 (DMZ) → em2

Menu console → 2 Set interface IP address
  LAN : 192.168.1.1/24 (activer DHCP server : yes)

2Accès web et mot de passe admin

Depuis un poste LAN : https://192.168.1.1
Login initial : admin / pfsense
Assistant → changer immédiatement le mot de passe

Configuration des interfaces

3WAN

Interfaces → WAN
  IPv4 Configuration Type : DHCP (ou Static selon FAI)
  Block private networks   : ✔
  Block bogon networks     : ✔

4LAN

Interfaces → LAN
  IPv4 : 192.168.1.1/24
Services → DHCP Server → LAN
  Range : 192.168.1.100 - 192.168.1.200

5DMZ (nouvelle interface)

Interfaces → Assignments → Available network ports
  Ajouter em2 → renommer "DMZ"

Interfaces → DMZ
  Enable : ✔
  IPv4 : 192.168.99.1/24
Services → DHCP Server → DMZ
  Range : 192.168.99.100 - 192.168.99.150

Règles pare-feu

6Règles LAN (par défaut : any-to-any autorisé)

Firewall → Rules → LAN

# Interdire LAN → DMZ (ou l'inverse selon besoin)
Action     : Block
Interface  : LAN
Source     : LAN net
Destination: DMZ net

# Autoriser LAN → Internet uniquement
Action     : Pass
Source     : LAN net
Destination: ! DMZ net

7Règles DMZ (isolation maximale)

Firewall → Rules → DMZ

# Bloquer DMZ → LAN (obligatoire)
Action : Block
Source : DMZ net
Destination : LAN net

# Autoriser DMZ → Internet
Action : Pass
Source : DMZ net
Destination : any (protocole HTTP/HTTPS/DNS)

NAT — publier un service DMZ vers Internet

8Port Forward (ex : serveur web DMZ)

Firewall → NAT → Port Forward → Add

Interface        : WAN
Protocol         : TCP
Destination      : WAN address
Destination port : HTTPS (443)
Redirect target  : 192.168.99.10 (IP serveur web DMZ)
Redirect port    : HTTPS
Filter rule assoc: Add associated filter rule (auto)

9Sauvegarde de la configuration

Diagnostics → Backup & Restore
  Download configuration as XML

# Fichier .xml à stocker hors du pfSense (Bitwarden, coffre-fort)

10Vérifications

Status → System Logs → Firewall     # voir les blocs/pass en temps réel
Diagnostics → States                 # sessions ouvertes
Diagnostics → Ping / Traceroute      # tests depuis pfSense
PIÈGE FRÉQUENT — Les règles pfSense sont évaluées de haut en bas et la première qui matche s'applique. Placer les règles spécifiques (block) au-dessus des règles génériques (allow).

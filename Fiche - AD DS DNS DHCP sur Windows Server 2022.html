WINDOWS SERVER 2022

Serveur AD DS / DNS / DHCP

À exécuter dans PowerShell en administrateur (clic droit → Exécuter en tant qu'administrateur).

Phase 1 — Préparation

1Renommer le serveur

Rename-Computer -NewName "SRV-AD01" -Restart

2Attribuer une IP fixe

New-NetIPAddress -InterfaceAlias "Ethernet" `
  -IPAddress 192.168.1.10 -PrefixLength 24 `
  -DefaultGateway 192.168.1.1

Set-DnsClientServerAddress -InterfaceAlias "Ethernet" `
  -ServerAddresses 127.0.0.1

Phase 2 — Active Directory + DNS

3Installer le rôle AD DS

Install-WindowsFeature AD-Domain-Services -IncludeManagementTools

4Promouvoir en contrôleur de domaine (nouvelle forêt)

Install-ADDSForest `
  -DomainName "monlab.local" `
  -DomainNetbiosName "MONLAB" `
  -InstallDNS `
  -ForestMode "WinThreshold" `
  -DomainMode "WinThreshold"
ATTENTION — Noter le mot de passe DSRM demandé, il sert à réparer l'AD en cas de panne. Le serveur redémarre à la fin.

5Vérifier AD et DNS

Get-ADDomain
Get-Service ADWS,KDC,Netlogon,DNS
nslookup monlab.local

Phase 3 — DHCP

6Installer le rôle DHCP

Install-WindowsFeature DHCP -IncludeManagementTools

7Autoriser le DHCP dans l'AD

Add-DhcpServerInDC -DnsName "SRV-AD01.monlab.local" -IPAddress 192.168.1.10
Add-DhcpServerSecurityGroup
Restart-Service dhcpserver

8Créer une étendue

Add-DhcpServerv4Scope -Name "LAN-Users" `
  -StartRange 192.168.1.100 -EndRange 192.168.1.200 `
  -SubnetMask 255.255.255.0 -State Active

Set-DhcpServerv4OptionValue -ScopeId 192.168.1.0 `
  -Router 192.168.1.1 `
  -DnsServer 192.168.1.10 `
  -DnsDomain "monlab.local"

9(Optionnel) Réserver une IP

Add-DhcpServerv4Reservation -ScopeId 192.168.1.0 `
  -IPAddress 192.168.1.50 -ClientId "AA-BB-CC-11-22-33" `
  -Description "Imprimante compta"

10Vérifier le DHCP

Get-DhcpServerv4Scope
Get-DhcpServerv4Lease -ScopeId 192.168.1.0

Phase 4 — OU + utilisateur (exemple)

11Créer une OU et un utilisateur

New-ADOrganizationalUnit -Name "Utilisateurs_Compta" `
  -Path "DC=monlab,DC=local"

New-ADUser -Name "Jean Dupont" -SamAccountName "jdupont" `
  -UserPrincipalName "jdupont@monlab.local" `
  -Path "OU=Utilisateurs_Compta,DC=monlab,DC=local" `
  -AccountPassword (ConvertTo-SecureString "P@ssw0rd!" -AsPlainText -Force) `
  -Enabled $true

Test client

PC en DHCP → doit obtenir une IP 192.168.1.100-200 → ipconfig /all pour vérifier le DNS → joindre le domaine monlab.local → se connecter avec MONLAB\jdupont.

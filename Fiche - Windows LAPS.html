Windows LAPS – Gestion des mots de passe admin locaux

Windows LAPS est intégré à Windows Server 2019+ et Windows 10/11 (avril 2023 et suivants). Il stocke automatiquement les mots de passe admin locaux dans l'AD, avec rotation programmée.

Côté contrôleur de domaine

1Vérifier la disponibilité

Get-Command Get-LapsADPassword

Si absent → mettre à jour Windows Server via WSUS/Windows Update.

2Étendre le schéma AD

Import-Module LAPS
Update-LapsADSchema

Répondre Y pour chaque attribut à ajouter (opération unique dans la forêt).

3Déléguer aux ordinateurs l'écriture de leur propre mot de passe

Cibler l'OU qui contient les postes clients :

Set-LapsADComputerSelfPermission -Identity "OU=Ordinateurs,DC=monlab,DC=local"

4Créer la GPO Windows LAPS

Ouvrir gpmc.msc → nouvelle GPO liée à l'OU des postes → éditer :

Configuration ordinateur → Stratégies → Modèles d'administration
  → Système → LAPS

Backup directory              : Active Directory
Password Age (Days)           : 30
Password Complexity           : Large + small + numbers + special
Password Length               : 20
Post-authentication actions   : Reset password + logoff (12h)

Côté poste client

5Appliquer et forcer une action LAPS

gpupdate /force
Invoke-LapsPolicyProcessing

Côté helpdesk / admin

6Consulter le mot de passe local d'un poste

Get-LapsADPassword -Identity "PC-COMPTA-01" -AsPlainText

7Forcer une rotation immédiate du mot de passe

Reset-LapsPassword -Identity "PC-COMPTA-01"

8Vérifier

# Sur le poste client - diagnostic complet
Get-LapsDiagnostics

# Événements Windows LAPS
Get-WinEvent -LogName "Microsoft-Windows-LAPS/Operational" -MaxEvents 20
SÉCURITÉ — Restreindre le droit Read sur les attributs LAPS aux seuls comptes Helpdesk / Sécurité. Auditer régulièrement les accès. Un mot de passe LAPS lu = un accès local admin sur ce poste.

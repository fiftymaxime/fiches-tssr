WINDOWS · CHIFFREMENT ENDPOINT

BitLocker – Chiffrement disque + sauvegarde AD

Étape préalable — GPO obligatoire avant tout déploiement

1Créer une GPO BitLocker

gpmc.msc → GPO liée à l'OU des postes → Éditer :

Configuration ordinateur → Modèles d'administration
  → Composants Windows → Chiffrement de lecteur BitLocker
  → Lecteurs du système d'exploitation

Activer :
  ✔ Choisir la manière dont les lecteurs BitLocker peuvent être récupérés
      - Enregistrer les informations dans les services AD DS
      - Ne pas activer BitLocker tant que les informations ne sont pas
        stockées dans AD DS

2Appliquer la GPO sur le poste

gpupdate /force

Côté poste client

3Vérifier le TPM

Get-Tpm

Vérifier : TpmPresent = True, TpmReady = True. Sinon activer le TPM dans le BIOS/UEFI.

4Activer BitLocker (PowerShell admin)

Enable-BitLocker -MountPoint "C:" `
  -EncryptionMethod XtsAes256 `
  -TpmProtector `
  -UsedSpaceOnly

5Sauvegarder la clé de récupération dans l'AD

$key = (Get-BitLockerVolume -MountPoint "C:").KeyProtector |
       Where-Object {$_.KeyProtectorType -eq "RecoveryPassword"}

Backup-BitLockerKeyProtector -MountPoint "C:" `
  -KeyProtectorId $key.KeyProtectorId

6Vérifier le statut du chiffrement

Get-BitLockerVolume -MountPoint "C:"
manage-bde -status

Côté helpdesk — récupération d'un poste bloqué

7Retrouver la clé dans l'AD

Get-ADObject -Filter {objectClass -eq "msFVE-RecoveryInformation"} `
  -SearchBase "CN=PC-COMPTA-01,OU=Ordinateurs,DC=monlab,DC=local" `
  -Properties msFVE-RecoveryPassword |
  Format-List Name,msFVE-RecoveryPassword

Ou par interface graphique : Utilisateurs et ordinateurs AD → clic droit sur l'ordinateur → onglet Récupération BitLocker.

8Suspendre / Reprendre / Décrypter

# Suspendre (avant maj BIOS, changement matériel)
Suspend-BitLocker -MountPoint "C:" -RebootCount 1

# Reprendre
Resume-BitLocker -MountPoint "C:"

# Décrypter complètement (rollback)
Disable-BitLocker -MountPoint "C:"
PIÈGE FRÉQUENT — Une mise à jour BIOS/UEFI, un changement de disque ou de carte mère déclenche l'écran de récupération BitLocker au démarrage. Toujours suspendre BitLocker avant toute opération matérielle, ou avoir la clé de récupération sous la main.

WINDOWS SERVER · GPO AD

GPO essentielles de sécurité

À appliquer via gpmc.msc. Politiques mot de passe/verrouillage compte = au niveau du domaine. Les autres = OU dédiée aux postes.

1Politique de mots de passe (niveau domaine)

Configuration ordinateur → Stratégies → Paramètres Windows
  → Paramètres de sécurité → Stratégies de comptes → Stratégie de mot de passe

Longueur minimale                    : 14 caractères
Complexité activée                   : Activé
Durée maximale                       : 90 jours
Durée minimale                       : 1 jour
Conserver l'historique               : 24 mots de passe
Stocker en réversible                : Désactivé

2Verrouillage de compte

...→ Stratégie de verrouillage du compte

Seuil de verrouillage                : 5 tentatives
Durée du verrouillage                : 15 minutes
Réinitialisation du compteur         : 15 minutes

3Verrouillage session inactive

Configuration ordinateur → Modèles d'administration
  → Panneau de configuration → Personnalisation

Activer l'écran de veille           : Activé
Protéger par mot de passe            : Activé
Délai (secondes)                     : 600

4Bloquer les périphériques USB de stockage

Configuration ordinateur → Modèles d'administration
  → Système → Accès au stockage amovible

Disques amovibles : Refuser accès en écriture : Activé
Disques amovibles : Refuser accès en lecture  : Activé (si besoin strict)

5PowerShell logging (indispensable pour SOC/audit)

Configuration ordinateur → Modèles d'administration
  → Composants Windows → Windows PowerShell

Activer la journalisation des modules  : Activé (Module : *)
Activer la journalisation des blocs    : Activé
Activer la transcription               : Activé
   Chemin de transcription             : \\SRV-LOG\PS-Logs$

6LSA Protection (contre vol de credentials type Mimikatz)

Configuration ordinateur → Modèles d'administration
  → Système → Autorité de sécurité locale

Configurer LSASS en tant que processus protégé : Activé (Enabled with UEFI Lock)

7Désactiver SMBv1 (vulnérable, exploité par EternalBlue/WannaCry)

Via GPO Registry ou en local sur chaque poste :

Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol

8Restreindre NTLM (utiliser Kerberos uniquement)

Configuration ordinateur → Stratégies → Paramètres Windows
  → Paramètres de sécurité → Stratégies locales → Options de sécurité

Sécurité réseau : Restreindre NTLM : Trafic NTLM entrant
  → Refuser tous les comptes de domaine

9Appliquer et vérifier

gpupdate /force

# Voir les GPO appliquées sur le poste
gpresult /r
gpresult /h C:\rapport-gpo.html   # rapport HTML complet
MÉTHODE — Toujours tester une GPO sur une OU pilote (1-2 postes) avant de généraliser. Une GPO mal ciblée peut bloquer tout le parc (ex : désactivation NTLM sur des vieilles imprimantes).

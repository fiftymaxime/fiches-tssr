LINUX · VPN

WireGuard — VPN moderne

Serveur (Debian)

1Installer WireGuard

sudo apt update
sudo apt install wireguard -y

2Générer les clés serveur

cd /etc/wireguard
sudo sh -c 'umask 077; wg genkey | tee server_priv | wg pubkey > server_pub'
sudo cat server_priv server_pub

3Créer /etc/wireguard/wg0.conf

[Interface]
Address = 10.10.0.1/24
ListenPort = 51820
PrivateKey = <contenu de server_priv>

# NAT sortant vers Internet
PostUp   = iptables -A FORWARD -i wg0 -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
PostDown = iptables -D FORWARD -i wg0 -j ACCEPT; iptables -t nat -D POSTROUTING -o eth0 -j MASQUERADE

# Un [Peer] par client (ajouter après création des clés client)
[Peer]
PublicKey  = <pubkey client 1>
AllowedIPs = 10.10.0.2/32

4Activer le forwarding IP

sudo sed -i 's/^#net.ipv4.ip_forward=1/net.ipv4.ip_forward=1/' /etc/sysctl.conf
sudo sysctl -p

5Démarrer le service

sudo systemctl enable --now wg-quick@wg0
sudo systemctl status wg-quick@wg0
sudo wg show

6Ouvrir le port dans le pare-feu

sudo ufw allow 51820/udp

Client

7Générer les clés client

wg genkey | tee client_priv | wg pubkey > client_pub

8Fichier de conf client client.conf

[Interface]
PrivateKey = <contenu de client_priv>
Address    = 10.10.0.2/32
DNS        = 1.1.1.1

[Peer]
PublicKey           = <server_pub>
Endpoint            = IP_PUBLIQUE_SERVEUR:51820
AllowedIPs          = 0.0.0.0/0        # tout le trafic passe par VPN
PersistentKeepalive = 25

9Ajouter le peer côté serveur

Éditer /etc/wireguard/wg0.conf et ajouter :
[Peer]
PublicKey  = <client_pub>
AllowedIPs = 10.10.0.2/32

sudo systemctl restart wg-quick@wg0

10Test

# Sur le client (Linux)
sudo wg-quick up ./client.conf
ping 10.10.0.1
curl ifconfig.me  # doit afficher l'IP publique du serveur

# App officielle sur Windows/macOS/iOS/Android : "WireGuard"
SÉCURITÉ — Les clés privées ne doivent jamais sortir du poste concerné. Générer les clés client directement sur le poste client, ne transmettre que la clé publique au serveur.

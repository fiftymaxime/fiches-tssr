LINUX · PARTAGE FICHIERS

Partage SMB (Samba) sur Debian

1Installer Samba

sudo apt update
sudo apt install samba samba-common-bin -y

2Sauvegarder la config d'origine

sudo cp /etc/samba/smb.conf /etc/samba/smb.conf.back

3Créer le dossier à partager

sudo mkdir -p /home/shared/sharedSMB
sudo chmod 777 /home/shared/sharedSMB

4Éditer smb.conf et déclarer le partage

sudo nano /etc/samba/smb.conf

Ajouter à la fin du fichier :

[MonPartage]
   path = /home/shared/sharedSMB
   readonly = no
   browseable = yes
   guest ok = yes

Enregistrer : Ctrl+O puis Entrée, quitter : Ctrl+X.

5(Optionnel) Créer un utilisateur Samba

sudo adduser sambauser
sudo smbpasswd -a sambauser

6Vérifier la syntaxe et redémarrer

testparm
sudo systemctl restart smbd nmbd
sudo systemctl status smbd

7Ouvrir le pare-feu

sudo ufw allow samba

8Tester l'accès

# Depuis Linux
smbclient -L //IP_SERVEUR -U sambauser

# Depuis Windows (barre d'adresse de l'Explorateur)
\\IP_SERVEUR\MonPartage
ATTENTION — chmod 777 et guest ok = yes sont à réserver aux tests / labo. En production : droits restreints et authentification obligatoire.

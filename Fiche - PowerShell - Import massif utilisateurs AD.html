WINDOWS SERVER · SCRIPTING AD

PowerShell – Création massive d'utilisateurs AD depuis un CSV

1Préparer le fichier CSV

Créer C:\Scripts\users.csv avec un séparateur ; :

Nom;Prenom;SamAccountName;OU;Groupe
Dupont;Jean;jdupont;OU=Compta,DC=monlab,DC=local;GG_Compta
Martin;Sophie;smartin;OU=RH,DC=monlab,DC=local;GG_RH
Durand;Paul;pdurand;OU=IT,DC=monlab,DC=local;GG_IT

2Créer le script Import-Users.ps1

Import-Module ActiveDirectory

$csv = Import-Csv -Path "C:\Scripts\users.csv" -Delimiter ";"
$log = "C:\Scripts\import-$(Get-Date -Format 'yyyyMMdd-HHmm').log"
$passwords = @()

foreach ($u in $csv) {

    # Génération d'un mot de passe aléatoire 14 caractères, 3 spéciaux
    Add-Type -AssemblyName System.Web
    $pwd = [System.Web.Security.Membership]::GeneratePassword(14,3)

    try {
        New-ADUser `
            -Name "$($u.Prenom) $($u.Nom)" `
            -GivenName $u.Prenom -Surname $u.Nom `
            -SamAccountName $u.SamAccountName `
            -UserPrincipalName "$($u.SamAccountName)@monlab.local" `
            -Path $u.OU `
            -AccountPassword (ConvertTo-SecureString $pwd -AsPlainText -Force) `
            -ChangePasswordAtLogon $true `
            -Enabled $true `
            -ErrorAction Stop

        Add-ADGroupMember -Identity $u.Groupe -Members $u.SamAccountName

        "$($u.SamAccountName);$pwd;OK" | Out-File $log -Append
        $passwords += [pscustomobject]@{
            User     = $u.SamAccountName
            Password = $pwd
        }
        Write-Host "OK  : $($u.SamAccountName)" -ForegroundColor Green
    }
    catch {
        "$($u.SamAccountName);;ERREUR - $($_.Exception.Message)" | Out-File $log -Append
        Write-Host "ERR : $($u.SamAccountName) - $($_.Exception.Message)" -ForegroundColor Red
    }
}

# Export des mots de passe pour transmission au helpdesk
$passwords | Export-Csv -Path "C:\Scripts\passwords.csv" `
    -Delimiter ";" -NoTypeInformation -Encoding UTF8

3Exécuter le script

powershell -ExecutionPolicy Bypass -File C:\Scripts\Import-Users.ps1

4Vérifier

# Comptes créés dans une OU
Get-ADUser -Filter * -SearchBase "OU=Compta,DC=monlab,DC=local"

# Erreurs dans le log
Get-Content C:\Scripts\import-*.log | Select-String "ERREUR"

5Transmettre les mots de passe de manière sécurisée

Ne jamais envoyer passwords.csv par mail en clair. Chiffrer avec 7-Zip et transmettre le mot de passe par un canal séparé (téléphone, SMS, coffre-fort d'équipe) :

& "C:\Program Files\7-Zip\7z.exe" a -tzip -mem=AES256 -p "C:\Scripts\pwd.zip" "C:\Scripts\passwords.csv"

# Puis supprimer le CSV en clair
Remove-Item "C:\Scripts\passwords.csv" -Force
SÉCURITÉ — Le fichier passwords.csv contient tous les mots de passe en clair. Le supprimer immédiatement après transmission chiffrée. En production : préférer un gestionnaire d'équipe (Bitwarden/Vaultwarden) qui génère un lien à usage unique par utilisateur.

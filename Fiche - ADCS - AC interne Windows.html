WINDOWS SERVER · PKI

ADCS — Autorité de certification interne

Objectif : émettre en interne des certificats X.509 pour les serveurs web internes, VPN, RADIUS, LDAPS, etc. Recommandation : installer sur un serveur membre dédié, pas sur le DC.

1Installer le rôle ADCS

Install-WindowsFeature ADCS-Cert-Authority -IncludeManagementTools

2Configurer l'AC racine d'entreprise

Install-AdcsCertificationAuthority `
  -CAType EnterpriseRootCA `
  -CACommonName "AC-Racine-MonLab" `
  -CryptoProviderName "RSA#Microsoft Software Key Storage Provider" `
  -KeyLength 4096 `
  -HashAlgorithmName SHA256 `
  -ValidityPeriod Years -ValidityPeriodUnits 10 `
  -Force

3Publier automatiquement dans l'AD

# Vérifier - le certificat racine doit être publié dans le conteneur AD
certutil -store -enterprise Root

4Publier le certificat racine sur tous les postes (GPO)

Exporter le certificat AC :
  certutil -ca.cert C:\Temp\AC-Racine.crt

GPO au niveau du domaine :
  Config ordinateur → Stratégies → Paramètres Windows → Paramètres de sécurité
    → Stratégies de clé publique → Autorités de certification racines de confiance
    → Importer AC-Racine.crt

5Créer un template certificat pour serveur web

certtmpl.msc → Modèles de certificats
  Clic droit sur "Serveur Web" → Dupliquer le modèle
  Onglet Général : Nom = "Serveur-Web-MonLab", validité 2 ans
  Onglet Sujet   : Fourni dans la demande
  Onglet Sécurité: Ajouter "Ordinateurs du domaine" → Lire + Inscrire
  Onglet Objet   : DNS Name (SAN)

6Publier le template

certsrv.msc → Modèles de certificats → Nouveau → Modèle de certificat à délivrer
  → Choisir "Serveur-Web-MonLab"

7Demander un certificat depuis un serveur

certlm.msc → Personnel → Certificats
  Clic droit → Toutes les tâches → Demander un nouveau certificat
  Politique d'inscription AD → Suivant
  Cocher "Serveur-Web-MonLab" → onglet Détails → Propriétés
  Onglet Objet : ajouter CN + SAN (nom DNS)
  Inscrire

8Demande via CSR (pour serveur Linux/appliance)

# Sur Linux, générer une CSR
openssl req -new -newkey rsa:2048 -nodes \
  -keyout srv-web.key -out srv-web.csr \
  -subj "/CN=srv-web.monlab.local"

# Copier srv-web.csr sur l'AC, puis
certreq -submit -attrib "CertificateTemplate:Serveur-Web-MonLab" srv-web.csr srv-web.crt

# Récupérer srv-web.crt et l'installer côté Linux

9Révoquer un certificat

certsrv.msc → Certificats délivrés
  Clic droit sur le cert → Toutes les tâches → Révoquer
  Motif : Compromis clé / Cessation d'activité / etc.

# Publier la nouvelle CRL
certutil -crl

10Vérifications

certutil -verify -urlfetch fichier.crt   # chaîne + CRL OK
certutil -pulse                            # force le renouvellement auto
SÉCURITÉ — Une AC interne compromise = tout le domaine compromis (usurpation Kerberos, LDAPS, VPN...). Ne jamais installer ADCS sur un DC, restreindre les admins ADCS à quelques comptes, auditer chaque émission de certificat.

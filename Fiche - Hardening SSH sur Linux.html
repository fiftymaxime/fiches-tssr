Hardening SSH sur Linux

AVANT DE COMMENCER — Garder une session SSH ouverte pendant toute la fiche. Ouvrir une seconde session pour tester chaque changement. Ne jamais fermer la session initiale tant que la nouvelle config n'est pas validée.

1Sauvegarder la config d'origine

sudo cp /etc/ssh/sshd_config /etc/ssh/sshd_config.back

2Générer une paire de clés (sur le poste client)

ssh-keygen -t ed25519 -C "monuser@monposte"

Créer une passphrase quand demandée. Fichiers créés : ~/.ssh/id_ed25519 (privée, à protéger) et ~/.ssh/id_ed25519.pub (publique).

3Copier la clé publique sur le serveur

ssh-copy-id -p 22 monuser@IP_SERVEUR

4Tester la connexion par clé (obligatoire avant l'étape 5)

ssh monuser@IP_SERVEUR

Connexion sans mot de passe (juste la passphrase de la clé) → OK, passer à la suite. Sinon, corriger avant de continuer.

5Durcir sshd_config

sudo nano /etc/ssh/sshd_config

Modifier / ajouter :

Port 2222                          # port non standard
PermitRootLogin no                 # pas de root direct
PasswordAuthentication no          # clés uniquement
PubkeyAuthentication yes
PermitEmptyPasswords no
MaxAuthTries 3
LoginGraceTime 30
ClientAliveInterval 300
ClientAliveCountMax 2
AllowUsers monuser                 # liste blanche d'utilisateurs
X11Forwarding no
Protocol 2

6Recharger SSH et tester dans une nouvelle session

sudo systemctl restart ssh
sudo systemctl status ssh

Dans un nouveau terminal : ssh -p 2222 monuser@IP_SERVEUR. Si OK → fermer la session initiale.

7Ouvrir le nouveau port dans le pare-feu

sudo ufw allow 2222/tcp
sudo ufw delete allow 22/tcp   # fermer l'ancien port SSH

8Installer et configurer Fail2Ban

sudo apt install fail2ban -y
sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local
sudo nano /etc/fail2ban/jail.local

Dans la section [sshd], ajouter/modifier :

[sshd]
enabled  = true
port     = 2222
maxretry = 3
bantime  = 3600
findtime = 600
sudo systemctl restart fail2ban
sudo fail2ban-client status sshd

9Vérifier

# Tentatives de connexion en direct
sudo journalctl -u ssh -f

# IP bannies
sudo fail2ban-client status sshd

# Débannir une IP
sudo fail2ban-client set sshd unbanip 192.168.1.42
PIÈGE FRÉQUENT — Ne jamais désactiver PasswordAuthentication sans avoir testé la connexion par clé au préalable. Sinon, accès bloqué (surtout à distance sans console de secours).

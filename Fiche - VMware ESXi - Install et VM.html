VIRTUALISATION · VMWARE

VMware ESXi — Install et déploiement d'une VM

1Télécharger l'ISO

Compte Broadcom (ex-VMware) requis :
  https://support.broadcom.com/group/ecx/downloads
  → VMware vSphere Hypervisor (ESXi 8.x)

2Installer ESXi depuis USB

Créer clé USB avec Rufus (mode DD)
Boot serveur sur USB → assistant :
  License agreement                    : F11
  Disque cible                         : (choisir le SSD dédié, pas de RAID logiciel)
  Root password
Reboot

3Config réseau (DCUI - console F2)

Login root → Configure Management Network
  IPv4          : IP fixe 192.168.1.30 / 24 / GW 192.168.1.1
  DNS           : 192.168.1.10, 1.1.1.1
  Hostname      : esxi01.monlab.local

Restart Management Network (Y)

4Accès web ESXi Host Client

https://192.168.1.30
Login : root / (mot de passe défini)

5Créer un datastore (VMFS)

Storage → Datastores → New datastore → Create new VMFS
  Nom       : datastore-vm
  Disque    : SSD 1 To
  Partition : 100% VMFS6

6Uploader une ISO

Storage → Datastores → datastore-vm → Datastore browser
  → New directory : ISO
  → Upload → sélectionner debian-12.iso

7Créer une VM

Virtual Machines → Create/Register VM → Create new VM

Name : srv-web-01
Compatibility : ESXi 8.0 U2
Guest OS family : Linux
Guest OS version : Debian GNU/Linux 12

Storage      : datastore-vm
CPU          : 2 cores
Memory       : 4 GB, cocher "Reserve all guest memory" si prod
Hard disk    : 60 GB, Thin provisioned
Network      : VM Network (VMXNET3)
CD/DVD Drive : Datastore ISO file → /ISO/debian-12.iso, cocher "Connect at power on"
Finish → Power on

8Snapshot

Clic droit VM → Snapshots → Take snapshot
  Name : avant-maj-kernel
  ✔ Snapshot the virtual machine's memory
  ✔ Quiesce guest file system (si VMware Tools installés)

9Installer VMware Tools (invité Linux)

sudo apt install open-vm-tools -y
sudo systemctl enable --now open-vm-tools

10Cloner une VM (méthode ESXi standalone)

# Sur ESXi (SSH activé)
cd /vmfs/volumes/datastore-vm
mkdir srv-web-02
vmkfstools -i srv-web-01/srv-web-01.vmdk srv-web-02/srv-web-02.vmdk -d thin
# Recréer la VM en pointant sur le nouveau vmdk

11Ligne de commande utile

esxcli vm process list                          # VM en cours
esxcli vm process kill --type=soft -w <WorldID>  # kill propre
esxcli hardware cpu list
esxcli storage vmfs extent list
esxcli network nic list
vim-cmd vmsvc/getallvms

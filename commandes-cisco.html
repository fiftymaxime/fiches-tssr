Modes et navigation 15

Sur IOS, une commande n'existe que dans son mode. L'invite indique toujours où l'on se trouve.

Router>Mode utilisateur : consultation seulement
Router#Mode privilégié : toutes les commandes show, sauvegarde, redémarrage
Router(config)#Configuration globale : ce qui concerne tout l'équipement
Router(config-if)#Configuration d'une interface
Router(config-subif)#Configuration d'une sous-interface (routage inter-VLAN)
Switch(config-vlan)#Configuration d'un VLAN
Se déplacer entre les modes
enablePasser du mode utilisateur au mode privilégié
disableRevenir au mode utilisateur
configure terminalEntrer en configuration globale — abrégé conf t
interface GigabitEthernet0/0Entrer dans le mode de configuration de cette interface
exitRemonter d'un seul niveau
endRevenir directement au mode privilégié (raccourci Ctrl+Z)
do show ip routeLancer une commande show sans quitter le mode configuration
Gagner du temps
conf tLes commandes IOS s'abrègent tant que l'abréviation reste unique
sh ip roAbrégé de show ip route — de même no sh pour no shutdown

Routage inter-VLAN 13

Faire communiquer les VLAN entre eux — deux méthodes.

Router-on-a-stick — sous-interfaces sur le routeur
interface fa0/24Côté commutateur : le port relié au routeur…
switchport mode trunk…doit être un trunk
interface GigabitEthernet0/0Côté routeur : l'interface physique…
no shutdown…doit être activée, même sans adresse IP
interface GigabitEthernet0/0.10Créer une sous-interface par VLAN
encapsulation dot1Q 10Rattacher la sous-interface au VLAN 10 — à faire avant l'adresse IP
ip address 192.168.10.254 255.255.255.0Cette adresse devient la passerelle des postes du VLAN 10
Commutateur de niveau 3 — interfaces SVI
ip routingActiver le routage sur le commutateur — sans ça, rien ne passe
interface vlan 10Créer l'interface virtuelle du VLAN 10
ip address 192.168.10.254 255.255.255.0Adresse de passerelle du VLAN
no shutdownUne interface VLAN reste inactive tant qu'elle n'est pas activée
Vérifier

ping 192.168.20.1Tester depuis un poste d'un VLAN vers la passerelle d'un autre

Listes de contrôle d'accès (ACL) 18

Filtrer le trafic. Une ACL se termine toujours par un refus implicite de tout le reste.

ACL standard — filtre sur la source uniquement (1 à 99)
access-list 10 permit 192.168.1.0 0.0.0.255Autoriser un sous-réseau — masque générique, pas masque de sous-réseau
access-list 10 deny host 192.168.1.50Bloquer une machine précise
access-list 10 permit anyAutoriser tout le reste — sinon le refus implicite bloque tout
ACL étendue — source, destination, protocole, port (100 à 199)
access-list 100 permit tcp 192.168.1.0 0.0.0.255 any eq 80Autoriser le web sortant depuis le LAN
access-list 100 permit tcp 192.168.1.0 0.0.0.255 any eq 443Idem en HTTPS
access-list 100 permit udp any any eq 53Laisser passer le DNS
access-list 100 permit icmp 192.168.1.0 0.0.0.255 anyAutoriser le ping depuis le LAN
access-list 100 deny tcp any any eq 23Bloquer Telnet
access-list 100 deny ip any anyRefus explicite final : le trafic refusé devient visible dans les compteurs
ACL nommée — plus lisible, et modifiable ligne par ligne
ip access-list standard MON-ACLCréer une ACL standard nommée
ip access-list extended FILTRAGE-LANCréer une ACL étendue nommée
10 permit tcp 192.168.1.0 0.0.0.255 any eq 443Chaque règle porte un numéro de séquence
no 10Supprimer une règle précise sans refaire toute l'ACL
Appliquer et vérifier
ip access-group 100 inAppliquer sur une interface, en entrée — out pour la sortie
no ip access-group 100 inRetirer l'ACL de l'interface
show access-listsToutes les ACL et leurs compteurs de correspondances
show ip interface GigabitEthernet0/0Voir quelle ACL est appliquée sur l'interface, et dans quel sens
clear access-list counters 100Remettre les compteurs à zéro avant un test

Sécurité des ports 9

Limiter les machines autorisées sur un port d'accès du commutateur.

switchport mode accessLa sécurité de port ne s'applique qu'à un port d'accès
switchport port-securityActiver la fonction sur le port
switchport port-security maximum 2Nombre d'adresses MAC autorisées simultanément
switchport port-security mac-address stickyApprendre l'adresse MAC connectée et la retenir dans la configuration
switchport port-security mac-address 00A1.B2C3.D4E5Déclarer une adresse MAC en dur
switchport port-security violation shutdownComportement en cas de violation — c'est le mode par défaut : le port est désactivé
switchport port-security violation restrictLe trafic fautif est bloqué et journalisé, le port reste actif
switchport port-security violation protectLe trafic fautif est bloqué en silence, sans alerte
show port-security interface fa0/1État, compteur de violations et adresses retenues

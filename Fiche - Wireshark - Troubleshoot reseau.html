RÉSEAU · ANALYSE

Wireshark — Troubleshoot réseau

1Choisir l'interface de capture

Wireshark → Capture → Options
  Sélectionner l'interface active (celle qui a du trafic)
  Cocher "Promiscuous mode" (voit aussi les paquets qui ne sont pas pour nous)

2Capture filter (avant capture — BPF syntax)

host 192.168.1.10                    # uniquement cet hôte
net 192.168.1.0/24                    # réseau entier
port 443                              # port spécifique
tcp port 80 or tcp port 443           # deux ports
not broadcast and not multicast       # réduire le bruit

3Display filter (après capture)

ip.addr == 192.168.1.10
ip.src == 192.168.1.10 and ip.dst == 8.8.8.8
tcp.port == 443
http.request.method == "POST"
dns.qry.name contains "google"
tcp.flags.reset == 1                  # RST uniquement
tcp.analysis.retransmission            # retransmissions détectées

4Analyser un handshake TCP

Filtre : tcp.stream eq 0
Suivre : clic droit sur un paquet → Follow → TCP Stream

À vérifier :
  [SYN] → [SYN, ACK] → [ACK]     # handshake normal
  [SYN] → [RST, ACK]              # service fermé / firewalled
  [SYN] → pas de réponse          # drop par firewall

5Détecter des retransmissions (lenteurs)

Filtre : tcp.analysis.retransmission

Statistiques → Expert Information
  Warnings : Duplicate ACK, Fast retransmission
  Notes    : Window Full, Zero Window

6Latence entre 2 paquets

Menu Statistics → TCP Stream Graphs → Round Trip Time
  Voir les pics de RTT

# Ou colonne dédiée : Wireshark → Preferences → Columns → +
# Field type : Delta time displayed

7Analyser un DNS

Filtres :
  dns
  dns.flags.response == 0            # requêtes seulement
  dns.flags.rcode != 0                # erreurs
  dns.qry.name == "srv-web.monlab.local"

8Analyser HTTP / HTTPS (SNI)

http.request.uri
http.response.code == 500
tls.handshake.extensions_server_name  # SNI (nom du site visé en HTTPS)

9Extraire des fichiers transférés

File → Export Objects → HTTP / SMB / FTP
  → Liste des objets transférés → Save All

10Capture depuis un poste sans GUI (tshark)

# Capture 60 secondes, filtrée
sudo tshark -i eth0 -f "host 192.168.1.10" -a duration:60 -w capture.pcap

# Lecture avec filtre display
tshark -r capture.pcap -Y "http.request" -T fields \
  -e ip.src -e http.host -e http.request.uri

11Capture à distance (SSH + Wireshark)

ssh user@srv-distant "sudo tcpdump -U -s0 -w - not port 22" | wireshark -k -i -
CONFIDENTIALITÉ — Une capture peut contenir des mots de passe (HTTP Basic, FTP, Telnet), des tokens, des cookies. Traiter les .pcap comme des fichiers sensibles : chiffrer au repos, supprimer après analyse, ne jamais partager en clair.

Création de VLAN et routage inter-VLAN

Configuration type Router-on-a-Stick (routeur avec sous-interfaces 802.1Q).

ServiceVLANRéseauPasserelle
Compta10192.168.10.0/24192.168.10.254
Informatique20192.168.20.0/24192.168.20.254

Sur le SWITCH

1Passer en mode configuration

enable
configure terminal

2Créer et nommer les VLAN

vlan 10
 name COMPTA
 exit

vlan 20
 name INFORMATIQUE
 exit

3Affecter les ports aux VLAN (mode access)

interface fastEthernet 0/1
 switchport mode access
 switchport access vlan 10
 exit

interface fastEthernet 0/2
 switchport mode access
 switchport access vlan 20
 exit

4(Astuce) Configurer plusieurs ports d'un coup

interface range fastEthernet 0/3 - 10
 switchport mode access
 switchport access vlan 10
 exit

5Configurer le port trunk vers le routeur

interface fastEthernet 0/24
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 exit

end
write memory

Sur le ROUTEUR

6Activer l'interface physique

enable
configure terminal

interface gigabitEthernet 0/0
 no shutdown
 exit

7Créer une sous-interface par VLAN

interface gigabitEthernet 0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.254 255.255.255.0
 exit

interface gigabitEthernet 0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.254 255.255.255.0
 exit

end
write memory

Vérifications

8Commandes de contrôle

# Sur le switch
show vlan brief
show interfaces trunk

# Sur le routeur
show ip interface brief
show ip route

9Config IP des PC

PC1 (VLAN 10)          PC2 (VLAN 20)
IP        : 192.168.10.1  IP        : 192.168.20.1
Masque    : 255.255.255.0 Masque    : 255.255.255.0
Passerelle: 192.168.10.254 Passerelle: 192.168.20.254

10Test

PC1> ping 192.168.20.1     # doit répondre
PC1> ping 192.168.10.254   # passerelle
PIÈGE COURANT — Oublier la passerelle sur le PC : le poste ne peut jamais joindre un autre VLAN. Vérifier aussi que le pare-feu Windows du PC cible autorise l'ICMP.

Prometheus + Grafana — Stack métriques moderne

Prometheus collecte, Grafana visualise. Utilisé partout dans les infras modernes / Kubernetes.

1Installer Prometheus (via Docker Compose)

sudo apt install docker.io docker-compose-plugin -y
mkdir -p ~/monitoring && cd ~/monitoring
nano docker-compose.yml
services:
  prometheus:
    image: prom/prometheus:latest
    container_name: prometheus
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
    ports: ["9090:9090"]
    restart: unless-stopped

  grafana:
    image: grafana/grafana:latest
    container_name: grafana
    ports: ["3000:3000"]
    volumes: ["grafana-data:/var/lib/grafana"]
    restart: unless-stopped

volumes:
  grafana-data:

2Config Prometheus (targets)

nano prometheus.yml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']

  - job_name: 'nodes'
    static_configs:
      - targets:
          - 'srv-web-01:9100'
          - 'srv-db-01:9100'
          - 'srv-app-01:9100'

3Démarrer la stack

docker compose up -d
docker ps

4Installer node_exporter sur chaque cible Linux

sudo useradd -rs /bin/false node_exporter
cd /tmp
wget https://github.com/prometheus/node_exporter/releases/download/v1.8.2/node_exporter-1.8.2.linux-amd64.tar.gz
tar -xf node_exporter-*.tar.gz
sudo mv node_exporter-*/node_exporter /usr/local/bin/

sudo nano /etc/systemd/system/node_exporter.service
[Unit]
Description=Node Exporter
After=network.target

[Service]
User=node_exporter
ExecStart=/usr/local/bin/node_exporter

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable --now node_exporter
sudo ss -tulpn | grep 9100

5Vérifier la collecte Prometheus

http://IP_PROMETHEUS:9090
  → Status → Targets : tous les hôtes doivent être "UP"

6Accéder à Grafana + ajouter Prometheus

http://IP_GRAFANA:3000
  Login : admin / admin → changer

Connections → Data sources → Add data source → Prometheus
  URL : http://prometheus:9090
  Save & Test

7Importer un dashboard prêt

Dashboards → New → Import → ID : 1860
  (Node Exporter Full - le plus utilisé)
Data source : Prometheus → Import

8Requêtes PromQL utiles

node_cpu_seconds_total                              # temps CPU par mode
100 - (avg by(instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)   # % CPU utilisé
node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes * 100               # % RAM dispo
100 - ((node_filesystem_avail_bytes / node_filesystem_size_bytes) * 100)         # % disque

9Configurer une alerte Grafana

Alerting → Alert rules → New alert rule
  Query : 100 - (avg(rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100) > 90
  Evaluate every : 1m for 5m
  Notifications : Contact point (Email, Slack, Teams...)

10Windows Exporter (équivalent node_exporter pour Windows)

# Télécharger le MSI depuis
# https://github.com/prometheus-community/windows_exporter/releases

msiexec /i windows_exporter-0.27.0-amd64.msi /qn `
  ENABLED_COLLECTORS="cpu,cs,logical_disk,net,os,service,system,textfile"

# Ajouter la cible dans prometheus.yml : 'srv-win:9182'
RÉTENTION — Par défaut Prometheus garde 15 jours. Pour plus, monter un volume et ajuster : --storage.tsdb.retention.time=90d. Pour beaucoup de données, utiliser Thanos ou VictoriaMetrics.

AUDIT · VULN MANAGEMENT

Nessus Essentials — Scan de vulnérabilités

Version gratuite : 16 IP max, non commercial. Alternative libre : OpenVAS/GVM.

Installation Nessus

1Télécharger + installer (Debian)

# Récupérer le .deb sur https://www.tenable.com/downloads/nessus
sudo dpkg -i Nessus-latest-debian10_amd64.deb
sudo systemctl start nessusd
sudo systemctl enable nessusd

2Accéder à l'interface web

https://IP_NESSUS:8834
  Choisir : Nessus Essentials
  Enregistrer avec un email → code d'activation reçu

3Attendre l'initialisation (plugins)

~30 minutes pour télécharger les 100 000+ plugins de détection.
Voir la progression dans l'interface web.

Créer et lancer un scan

4Nouveau scan

Scans → New Scan → Templates

Choix courants :
  - Basic Network Scan       (audit standard interne)
  - Advanced Scan            (personnalisation totale)
  - Web Application Tests    (audit site web)
  - Credentialed Patch Audit (avec compte : plus précis)

5Configuration du scan

Onglet Settings :
  Name          : Audit-Interne-2026-07
  Targets       : 192.168.1.0/24
  Schedule      : Once / Weekly / etc.

Onglet Credentials (recommandé, sinon scan "black box") :
  SSH / Windows / SNMP → compte de service en lecture seule
  → Nessus se connecte et audite les patches manquants, config, etc.

Onglet Plugins :
  Désactiver les familles non pertinentes (économise du temps)

6Lancer et suivre le scan

Save → Launch
  Durée : 30 min à plusieurs heures selon la cible

Analyser les résultats

7Comprendre la criticité (CVSS)

Critical : 9.0 - 10.0    # patcher immédiatement
High     : 7.0 - 8.9
Medium   : 4.0 - 6.9
Low      : 0.1 - 3.9
Info     : (pas une vuln, juste une info)

8Prioriser via VPR (Vulnerability Priority Rating)

Onglet Vulnerabilities → colonne VPR
  Score Tenable qui combine CVSS + exploitation active + threat intelligence
  → Traiter les VPR >= 7 en priorité

9Exporter le rapport

Report → Formats disponibles :
  - HTML          (partage direction)
  - PDF           (archivage)
  - CSV           (import GLPI/JIRA)
  - Nessus (.nessus) (import dans autre Nessus)

10Suivi (remédiation)

Pour chaque vuln :
  - CVE + CVSS
  - Description
  - Solution (KB Microsoft, patch éditeur, contournement)
  - See Also (liens exploits, avis ANSSI)
  - Output (preuve technique de la détection)

Créer un ticket GLPI par vuln critique → assignation → validation post-patch

Alternative libre — OpenVAS / GVM

11Install rapide via Docker

sudo apt install docker.io docker-compose -y
curl -f -L https://greenbone.github.io/docs/latest/_static/setup-and-start-greenbone-community-edition.sh > gvm.sh
chmod +x gvm.sh
sudo ./gvm.sh

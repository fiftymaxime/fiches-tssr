SAUVEGARDE · NATIF OS

Sauvegardes natives — wbadmin (Windows) & rsync (Linux)

Windows — wbadmin (Windows Server Backup)

1Installer la fonctionnalité

Install-WindowsFeature -Name Windows-Server-Backup -IncludeManagementTools

2Sauvegarde complète (Bare Metal)

wbadmin start backup `
  -backupTarget:E: `
  -allCritical `
  -include:C: `
  -vssFull -quiet

3Sauvegarde de dossiers spécifiques

wbadmin start backup `
  -backupTarget:\\SRV-BACKUP\Backup$ `
  -include:C:\Data,C:\Users\ImportantUser `
  -user:MONLAB\backup -password:MotDePasse -quiet

4Planifier une sauvegarde quotidienne

wbadmin enable backup `
  -addtarget:E: `
  -include:C: -allCritical `
  -schedule:02:00 -vssFull -quiet

5Lister les sauvegardes disponibles

wbadmin get versions

6Restaurer un fichier

wbadmin start recovery `
  -version:07/25/2026-02:00 `
  -itemType:File `
  -items:C:\Data\dossier `
  -recoveryTarget:D:\Restore `
  -notRestoreAcl -quiet

7Restaurer un système complet (Bare Metal Recovery)

Booter sur ISO Windows Server → Repair → Advanced → System Image Recovery
Ou depuis Windows RE : wbadmin start sysrecovery -version:...

Linux — rsync avec rotation incrémentale

8Installation

sudo apt install rsync -y

9Sauvegarde simple

rsync -avh --delete /home/ user@srv-backup:/backup/home/

# Options :
# -a : archive (récursif + permissions + liens + timestamps)
# -v : verbose  |  -h : human-readable
# --delete : supprime dans dest ce qui n'existe plus dans source
# -z : compression réseau (utile en WAN)

10Sauvegarde incrémentale économe (--link-dest)

DATE=$(date +%F)
LAST=$(ls -1 /backup/ | tail -n 1)

rsync -avh --delete \
  --link-dest=/backup/$LAST \
  /home/ /backup/$DATE/

# Résultat : chaque backup ressemble à une copie complète, mais
# les fichiers inchangés sont des hard links vers la précédente
# → gain d'espace énorme (seuls les changements consomment)

11Rotation automatique (garder 7/4/3)

find /backup/ -maxdepth 1 -type d -mtime +7 -exec rm -rf {} \;
# Supprime les backups > 7 jours

12Script complet + cron

sudo nano /usr/local/bin/backup.sh
#!/bin/bash
SRC="/home/"
DEST="/backup"
DATE=$(date +%F-%H%M)
LAST=$(ls -1t $DEST | head -n 1)

if [ -n "$LAST" ]; then
    LINKDEST="--link-dest=$DEST/$LAST"
fi

rsync -avh --delete $LINKDEST $SRC $DEST/$DATE/ > /var/log/backup-$DATE.log 2>&1

# Rotation - garde 14 backups
ls -1t $DEST | tail -n +15 | xargs -I{} rm -rf $DEST/{}
sudo chmod +x /usr/local/bin/backup.sh
sudo crontab -e

0 2 * * * /usr/local/bin/backup.sh

13Restauration

rsync -avh /backup/2026-07-25-0200/etc/nginx/ /etc/nginx/
# Ou copie manuelle : cp -a /backup/... /destination

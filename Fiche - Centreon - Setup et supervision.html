SUPERVISION · CENTREON

Centreon — Setup et supervision d'un hôte

Méthode la plus rapide : ISO Centreon Community (basée sur AlmaLinux 9). Prévoir VM 4 vCPU / 8 Go / 80 Go.

1Installation depuis l'ISO

Télécharger : https://download.centreon.com/
  Version : Centreon Central + BAM 24.x

Boot sur l'ISO → suivre l'assistant :
  Type d'install : Central with database
  Timezone       : Europe/Paris
  Root password  : (fort)
Reboot

2Configuration initiale web

http://IP_CENTREON/centreon

Étape 1 : chemins par défaut → Next
Étape 2 : broker → Next
Étape 3 : admin user - définir centreon-admin / MotDePasse
Étape 4 : DB - MariaDB root password
Étape 5 : install modules → Next
Étape 6 : Finalize

3Login et premiers réglages

Login : admin / (mot de passe défini)
Administration → Parameters → General : ajuster timezone, langue FR

4Installer le collecteur (Poller) sur les cibles

# Sur chaque poller distant (ou en local sur le Central)
dnf install centreon-poller -y

5Installer l'agent SNMP sur un hôte Linux

# Sur le serveur à monitorer
sudo apt install snmpd -y
sudo nano /etc/snmp/snmpd.conf

agentAddress udp:161
rocommunity ma_communaute IP_CENTREON

sudo systemctl restart snmpd

6Ajouter un hôte dans Centreon

Configuration → Hosts → Add
  Name          : srv-web-01
  Alias         : Serveur web
  IP address    : 192.168.1.20
  Templates     : OS-Linux-SNMP-custom
  SNMP version  : 2c
  Community     : ma_communaute
  Save

7Ajouter des services à surveiller

Configuration → Services → Add

Ex : CPU
  Description : CPU
  Linked with hosts : srv-web-01
  Template : OS-Linux-Snmp-Cpu-custom

Répéter pour : Memory, Disk-/, Ping, HTTP, Uptime

8Générer et pousser la config vers le poller

Configuration → Pollers → Export configuration
  ✔ Generate Configuration Files
  ✔ Run monitoring engine debug
  ✔ Move Export Files
  ✔ Restart Monitoring Engine
  Export

9Vérifier la remontée

Monitoring → Hosts → doit passer en UP (vert)
Monitoring → Services → doit passer en OK

# Si problème :
tail -f /var/log/centreon-engine/centreon-engine.log

10Configurer les notifications

Configuration → Users → admin
  Notifications enabled : Yes
  Email                : admin@monlab.local
  Notify on            : Down, Unreachable, Recovery
  Time period          : 24x7

Configuration → Notifications → Contact groups
  → assigner l'admin au bon host/service

11Cartographie temps réel

Monitoring → Map
  Créer une vue avec les hôtes critiques positionnés
  Statuts en direct visibles sur écran mural (NOC)
APRÈS CHAQUE MODIF — Toute modification de config (host, service, template) doit être suivie d'un Export configuration avec redémarrage moteur, sinon les changements ne sont pas actifs.

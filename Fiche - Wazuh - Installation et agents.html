Wazuh — Installation serveur + agents

Prérequis : VM dédiée Debian/Ubuntu, 4 vCPU / 8 Go RAM min, 50 Go disque.

Serveur Wazuh (all-in-one)

1Installation via script officiel

curl -sO https://packages.wazuh.com/4.9/wazuh-install.sh
sudo bash wazuh-install.sh -a

Le script installe Wazuh Manager + Indexer + Dashboard. Compter 10-15 minutes.

2Récupérer les identifiants admin

sudo tar -xvf wazuh-install-files.tar wazuh-install-files/wazuh-passwords.txt
cat wazuh-install-files/wazuh-passwords.txt | grep "'admin'" -A 1

3Accès Dashboard

https://IP_WAZUH
Login : admin / (mot de passe récupéré ci-dessus)

Déploiement d'agent — Linux

4Générer les commandes depuis le dashboard

Dashboard → Agents → Deploy new agent
  OS : Linux DEB amd64
  Server address : IP_WAZUH
  Agent name    : srv-web-01

Le dashboard génère les commandes à exécuter sur l'agent. Exemple :

curl -so wazuh-agent.deb https://packages.wazuh.com/4.x/apt/pool/main/w/wazuh-agent/wazuh-agent_4.9.0-1_amd64.deb

WAZUH_MANAGER='IP_WAZUH' sudo dpkg -i ./wazuh-agent.deb

sudo systemctl daemon-reload
sudo systemctl enable --now wazuh-agent

Déploiement d'agent — Windows

5Installation (PowerShell admin)

Invoke-WebRequest -Uri https://packages.wazuh.com/4.x/windows/wazuh-agent-4.9.0-1.msi `
  -OutFile $env:tmp\wazuh-agent.msi

msiexec.exe /i $env:tmp\wazuh-agent.msi /q `
  WAZUH_MANAGER='IP_WAZUH' `
  WAZUH_AGENT_NAME='PC-COMPTA-01'

Start-Service WazuhSvc

6Vérifier l'agent côté serveur

Dashboard → Agents → doit apparaître "Active"

# Ou en CLI sur le serveur
sudo /var/ossec/bin/agent_control -l

Configuration des règles et alertes

7Modifier la config d'un agent (à distance)

sudo nano /var/ossec/etc/shared/default/agent.conf

# Ajouter par exemple la surveillance d'un dossier
<syscheck>
  <directories realtime="yes" report_changes="yes">/etc,/var/www</directories>
</syscheck>

sudo systemctl restart wazuh-manager

8Rechercher des événements

Dashboard → Threat Hunting → Events
  Filtres : agent.name, rule.level, data.srcip
  Requête KQL : rule.level: >=10 AND agent.name: "srv-web-01"

9Notifications email/Slack

sudo nano /var/ossec/etc/ossec.conf

<global>
  <email_notification>yes</email_notification>
  <smtp_server>smtp.gmail.com</smtp_server>
  <email_from>wazuh@monlab.local</email_from>
  <email_to>soc@monlab.local</email_to>
</global>

<alerts>
  <email_alert_level>10</email_alert_level>
</alerts>
PERFORMANCE — Un serveur all-in-one supporte ~100-300 agents. Au-delà, séparer Manager / Indexer / Dashboard sur des VMs distinctes et prévoir un cluster Indexer.

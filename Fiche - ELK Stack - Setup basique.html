ELK Stack — Setup basique (Elasticsearch + Kibana + Logstash)

Cible : VM Debian 12, 4 vCPU / 8 Go RAM / 100 Go. Installation par paquets Elastic.

1Ajouter le dépôt Elastic

sudo apt install -y apt-transport-https gnupg
wget -qO - https://artifacts.elastic.co/GPG-KEY-elasticsearch | sudo gpg --dearmor -o /usr/share/keyrings/elastic.gpg
echo "deb [signed-by=/usr/share/keyrings/elastic.gpg] https://artifacts.elastic.co/packages/8.x/apt stable main" | \
  sudo tee /etc/apt/sources.list.d/elastic-8.x.list
sudo apt update

2Installer Elasticsearch

sudo apt install elasticsearch -y

Noter le mot de passe généré pour elastic. Sinon le régénérer :

sudo /usr/share/elasticsearch/bin/elasticsearch-reset-password -u elastic

3Configurer et démarrer Elasticsearch

sudo nano /etc/elasticsearch/elasticsearch.yml

network.host: 0.0.0.0
http.port: 9200
discovery.type: single-node

sudo systemctl enable --now elasticsearch
curl -k -u elastic https://localhost:9200

4Installer Kibana

sudo apt install kibana -y

5Générer le token d'inscription Kibana

sudo /usr/share/elasticsearch/bin/elasticsearch-create-enrollment-token -s kibana

6Configurer et démarrer Kibana

sudo nano /etc/kibana/kibana.yml

server.host: "0.0.0.0"
server.port: 5601

sudo systemctl enable --now kibana

Accéder à http://IP_ELK:5601, coller le token, puis récupérer le code de vérification :

sudo /usr/share/kibana/bin/kibana-verification-code

7Installer Logstash (pour le parsing)

sudo apt install logstash -y

8Pipeline Logstash minimal

sudo nano /etc/logstash/conf.d/syslog.conf

input {
  beats { port => 5044 }
}

filter {
  if [event][module] == "system" {
    grok { match => { "message" => "%{SYSLOGBASE} %{GREEDYDATA:msg}" } }
  }
}

output {
  elasticsearch {
    hosts    => ["https://localhost:9200"]
    user     => "elastic"
    password => "MotDePasse"
    ssl_certificate_verification => false
    index    => "logs-%{+YYYY.MM.dd}"
  }
}

sudo systemctl enable --now logstash

9Filebeat côté client (envoi des logs)

# Sur chaque serveur/poste à monitorer
sudo apt install filebeat -y
sudo nano /etc/filebeat/filebeat.yml

output.logstash:
  hosts: ["IP_ELK:5044"]

sudo filebeat modules enable system
sudo systemctl enable --now filebeat

10Créer un Data View dans Kibana

Kibana → Discover → Create data view
  Name  : logs-*
  Time field : @timestamp
SÉCURITÉ — L'installation par défaut a le TLS activé (bien) mais avec un certificat auto-signé. En production, remplacer par un certificat émis par une AC interne ou publique.

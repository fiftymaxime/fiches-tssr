Installation de GLPI sur Debian

Phase 1 — Serveur LAMP

1Mettre à jour le système

sudo apt update && sudo apt upgrade -y

2Installer Apache, MariaDB, PHP + modules

sudo apt install -y apache2 mariadb-server \
  php php-{mysql,curl,gd,intl,mbstring,xml,zip,bz2,ldap,apcu,xmlrpc,cas}

Phase 2 — Base de données

3Sécuriser MariaDB

sudo mysql_secure_installation

Répondre Y à toutes les questions de sécurité et définir un mot de passe root.

4Créer la base et l'utilisateur GLPI

sudo mysql -u root -p

À l'invite MariaDB [(none)]> :

CREATE DATABASE glpidb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'glpiuser'@'localhost' IDENTIFIED BY 'MotDePasseFort';
GRANT ALL PRIVILEGES ON glpidb.* TO 'glpiuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;

5Activer les fuseaux horaires (requis par GLPI 10)

sudo mysql_tzinfo_to_sql /usr/share/zoneinfo | sudo mysql -u root -p mysql

sudo mysql -u root -p -e \
  "GRANT SELECT ON mysql.time_zone_name TO 'glpiuser'@'localhost'; FLUSH PRIVILEGES;"

Phase 3 — GLPI

6Télécharger et extraire GLPI

cd /tmp
wget https://github.com/glpi-project/glpi/releases/download/10.0.15/glpi-10.0.15.tgz
tar -xvzf glpi-10.0.15.tgz
sudo mv glpi /var/www/html/

Vérifier la dernière version sur github.com/glpi-project/glpi/releases.

7Attribuer les droits à Apache

sudo chown -R www-data:www-data /var/www/html/glpi
sudo chmod -R 755 /var/www/html/glpi

8Redémarrer Apache + activer au démarrage

sudo systemctl restart apache2
sudo systemctl enable apache2 mariadb

Phase 4 — Assistant Web

9Lancer l'installation navigateur

Ouvrir : http://IP_SERVEUR/glpi

Serveur SQL    : localhost
Utilisateur    : glpiuser
Mot de passe   : MotDePasseFort
Base de données: glpidb

Comptes créés par défaut : glpi/glpi, tech/tech, normal/normal, post-only/postonly.

Phase 5 — Sécurisation obligatoire

10Supprimer le fichier d'installation

sudo rm /var/www/html/glpi/install/install.php
CRITIQUE — Modifier immédiatement le mot de passe des 4 comptes par défaut depuis Administration → Utilisateurs. Ces identifiants sont publics.

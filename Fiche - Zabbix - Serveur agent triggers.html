Zabbix — Serveur, agent, triggers, alertes

Installation du serveur (Debian 12)

1Ajouter le dépôt Zabbix

wget https://repo.zabbix.com/zabbix/7.0/debian/pool/main/z/zabbix-release/zabbix-release_latest+debian12_all.deb
sudo dpkg -i zabbix-release_latest+debian12_all.deb
sudo apt update

2Installer serveur + frontend + agent + MariaDB

sudo apt install -y zabbix-server-mysql zabbix-frontend-php \
  zabbix-nginx-conf zabbix-sql-scripts zabbix-agent mariadb-server

3Créer la base de données

sudo mysql -uroot
CREATE DATABASE zabbix character set utf8mb4 collate utf8mb4_bin;
CREATE USER 'zabbix'@'localhost' IDENTIFIED BY 'MotDePasse';
GRANT ALL PRIVILEGES ON zabbix.* TO 'zabbix'@'localhost';
SET GLOBAL log_bin_trust_function_creators = 1;
QUIT;

sudo zcat /usr/share/zabbix-sql-scripts/mysql/server.sql.gz | mysql -uzabbix -p zabbix

4Config serveur Zabbix

sudo nano /etc/zabbix/zabbix_server.conf
DBPassword=MotDePasse

sudo nano /etc/zabbix/nginx.conf
listen 8080;
server_name IP_ZABBIX;

sudo systemctl restart zabbix-server zabbix-agent nginx php8.2-fpm
sudo systemctl enable zabbix-server zabbix-agent nginx php8.2-fpm

5Assistant Web

http://IP_ZABBIX:8080
  Config DB : localhost, zabbix, MotDePasse
  Timezone  : Europe/Paris
  Login initial : Admin / zabbix  → CHANGER IMMÉDIATEMENT

Déploiement d'agent

6Agent Linux

sudo apt install zabbix-agent2 -y
sudo nano /etc/zabbix/zabbix_agent2.conf

Server=IP_ZABBIX
ServerActive=IP_ZABBIX
Hostname=srv-web-01

sudo systemctl restart zabbix-agent2
sudo systemctl enable zabbix-agent2

7Agent Windows

# Télécharger MSI sur zabbix.com/download_agents
msiexec /i zabbix_agent2-7.0.0-windows-amd64-openssl.msi /qn `
  SERVER=IP_ZABBIX SERVERACTIVE=IP_ZABBIX HOSTNAME=PC-COMPTA-01

Ajouter des hôtes et templates

8Créer un hôte dans Zabbix

Data collection → Hosts → Create host
  Host name  : srv-web-01   (identique à Hostname côté agent)
  Groups     : Linux servers
  Interfaces : Agent - 192.168.1.20 - 10050
  Templates  : Linux by Zabbix agent
  Add

9Créer un trigger custom (ex : filesystem > 90%)

Data collection → Templates → Linux by Zabbix agent → Triggers → Create

Name       : Disque plein sur {HOST.NAME}
Expression : last(/Linux by Zabbix agent/vfs.fs.size[/,pused]) > 90
Severity   : High

10Configurer une alerte email/Slack

Alerts → Media types → Email → Configurer SMTP

Users → Admin → Media → Add
  Type    : Email
  Send to : soc@monlab.local

Alerts → Actions → Trigger actions → Create action
  Conditions : Trigger severity ≥ High
  Operations : Send message to Admin

11Vérifications

Monitoring → Hosts → doit afficher ZBX en vert
Monitoring → Latest data → voir les métriques remonter
Reports → Action log → historique des alertes envoyées
PIÈGE FRÉQUENT — Le Hostname côté agent DOIT correspondre au Host name côté serveur (sensible à la casse). Sinon l'hôte reste inaccessible.

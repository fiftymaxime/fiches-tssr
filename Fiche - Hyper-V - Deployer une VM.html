WINDOWS · VIRTUALISATION

Hyper-V — Activer, vSwitch, VM, snapshot

1Prérequis (BIOS)

Activer dans le BIOS/UEFI :
  - Intel VT-x / AMD-V
  - VT-d / AMD-Vi (IOMMU)

Vérifier dans Windows :
  systeminfo | Select-String "Hyper-V"

2Activer Hyper-V (Windows Server)

Install-WindowsFeature -Name Hyper-V -IncludeManagementTools -Restart

3Activer Hyper-V (Windows 10/11 Pro)

Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All
# Redémarrer

4Créer un commutateur virtuel (vSwitch)

# External : VM accèdent au réseau physique
New-VMSwitch -Name "vSwitch-Ext" -NetAdapterName "Ethernet" -AllowManagementOS $true

# Internal : VM ↔ hôte uniquement
New-VMSwitch -Name "vSwitch-Int" -SwitchType Internal

# Private : VM ↔ VM uniquement
New-VMSwitch -Name "vSwitch-Priv" -SwitchType Private

Get-VMSwitch

5Créer une VM (PowerShell)

$VMPath  = "D:\Hyper-V"
$VMName  = "srv-web-01"
$VHDPath = "$VMPath\$VMName\$VMName.vhdx"

New-VM -Name $VMName -MemoryStartupBytes 4GB `
  -NewVHDPath $VHDPath -NewVHDSizeBytes 60GB `
  -SwitchName "vSwitch-Ext" -Generation 2

Set-VM -Name $VMName -ProcessorCount 2 `
  -DynamicMemory -MemoryMinimumBytes 2GB -MemoryMaximumBytes 8GB

# Attacher l'ISO d'installation
Add-VMDvdDrive -VMName $VMName -Path "D:\ISO\debian-12.iso"

# Booter en premier sur le DVD
Set-VMFirmware -VMName $VMName -FirstBootDevice (Get-VMDvdDrive -VMName $VMName)

Start-VM -Name $VMName
vmconnect localhost $VMName    # ouvrir la console

6Checkpoint (snapshot)

Checkpoint-VM -Name $VMName -SnapshotName "avant-maj"
Get-VMSnapshot -VMName $VMName

7Restaurer un checkpoint

Restore-VMSnapshot -VMName $VMName -Name "avant-maj" -Confirm:$false

8Export / import (déplacer une VM)

Export-VM -Name $VMName -Path "D:\Exports\"

# Sur l'hôte cible
Import-VM -Path "D:\Exports\srv-web-01\Virtual Machines\XXX.vmcx" -Copy -GenerateNewId

9Réplication Hyper-V (PRA)

# Sur l'hôte cible (réplica) : activer
Set-VMReplicationServer -ReplicationEnabled $true `
  -AllowedAuthenticationType Kerberos -DefaultStorageLocation "D:\Replicas"

# Sur l'hôte source
Enable-VMReplication -VMName $VMName -ReplicaServerName "HV-DR-01" `
  -ReplicaServerPort 80 -AuthenticationType Kerberos

Start-VMInitialReplication -VMName $VMName

10Sauvegarde d'une VM avec wbadmin

wbadmin start backup -backupTarget:E: -hyperv:"srv-web-01" -quiet

11Commandes utiles

Get-VM                            # liste des VM
Get-VM | Format-Table Name,State,CPUUsage,MemoryAssigned
Stop-VM -Name $VMName -Save
Start-VM -Name $VMName
Remove-VM -Name $VMName -Force    # supprime la VM (pas le VHDX)
GENERATION 2 — Recommandée pour Windows 8+ / Linux moderne : UEFI, Secure Boot, boot rapide. Generation 1 uniquement pour vieux OS (Windows Server 2003, etc.). Impossible de changer après création.

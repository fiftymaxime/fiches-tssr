PARE-FEU · FORTIGATE

FortiGate — Setup initial et politiques

Accès initial (console série)

1Connexion console

Câble console RJ45 → série USB
Terminal (PuTTY) : 9600 8-N-1
Login initial    : admin / (vide) → forcer mot de passe

2Configurer l'IP de management

config system interface
  edit port1
    set mode static
    set ip 192.168.1.99 255.255.255.0
    set allowaccess https ssh ping
  next
end

3Accès web GUI

Depuis un poste LAN : https://192.168.1.99
Login admin

Configuration réseau

4Interfaces (via GUI)

Network → Interfaces

port1 (LAN)  → Role : LAN,  IP 192.168.1.99/24, DHCP server actif
port2 (WAN)  → Role : WAN,  DHCP (ou IP statique FAI)
port3 (DMZ)  → Role : DMZ,  IP 192.168.99.1/24

5Objets réservables (Address / Service)

Policy & Objects → Addresses → Create New
  Name    : SRV-WEB-DMZ
  Type    : Subnet
  Subnet  : 192.168.99.10/32
  Interface : port3

Policy & Objects → Services → Create New
  Name : SRV-HTTPS
  Protocol : TCP, port 443

Politiques pare-feu

6Politique LAN → WAN (accès Internet)

Policy & Objects → Firewall Policy → Create New

Name         : LAN-to-Internet
Incoming     : port1 (LAN)
Outgoing     : port2 (WAN)
Source       : all
Destination  : all
Service      : ALL
Action       : ACCEPT
NAT          : Enabled (use outgoing interface address)
Log Allowed  : All Sessions

7Politique WAN → DMZ (publier serveur)

Policy & Objects → Virtual IPs → Create New (DNAT)
  Name         : VIP-Web
  Interface    : port2 (WAN)
  External IP  : @IP publique WAN
  Mapped IP    : 192.168.99.10

Policy & Objects → Firewall Policy → Create New
  Incoming     : port2 (WAN)
  Outgoing     : port3 (DMZ)
  Destination  : VIP-Web
  Service      : HTTPS
  Action       : ACCEPT

8Isolation DMZ ↔ LAN

Créer une politique explicite :
  DMZ → LAN : Action DENY (log Deny)

Sauvegarde et vérifications

9Sauvegarde config

System → Configuration → Backup
  Scope : Global
  Encryption : ✔ (mot de passe)
  Download

10Vérifications CLI

# Sessions en cours
diagnose sys session list

# Logs traffic en direct
diagnose log console output enable

# Test de politique
diagnose firewall packet-mode 4-2-6-7 # voir quelle policy matche
MÉTHODE — Toujours activer Log Allowed Traffic: All Sessions pendant la mise en place, puis basculer sur "Security Events" en production (moins de logs).

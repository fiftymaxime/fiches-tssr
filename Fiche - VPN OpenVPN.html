OpenVPN — Serveur + client (script rapide)

Méthode la plus rapide : script openvpn-install.sh (angristan) qui automatise PKI + config.

1Installation via script officiel

curl -O https://raw.githubusercontent.com/angristan/openvpn-install/master/openvpn-install.sh
chmod +x openvpn-install.sh
sudo ./openvpn-install.sh

Répondre :

IP publique              : auto-détectée
Protocole                : UDP (recommandé)
Port                     : 1194 (ou custom)
DNS pour le client       : 1.1.1.1 / Cloudflare
Client compressed        : No
Encryption               : AES-256-GCM
Certificate curve        : prime256v1
Auth digest              : SHA256

Nom du 1er client        : max-portable

2Fichier .ovpn du client

ls /root/*.ovpn
# → /root/max-portable.ovpn

Ce fichier contient tout : certificats, clé privée, config. À transmettre au client par canal sécurisé.

3Ajouter un nouveau client

sudo ./openvpn-install.sh
# → choisir "1) Add a new user"

4Révoquer un client

sudo ./openvpn-install.sh
# → choisir "2) Revoke existing user"

5Vérifier le service

sudo systemctl status openvpn-server@server
sudo ss -tulpn | grep openvpn

6Voir les clients connectés

sudo cat /var/log/openvpn/status.log

7Ouvrir le pare-feu (si pas fait par le script)

sudo ufw allow 1194/udp
sudo ufw allow OpenSSH
sudo ufw enable

8Connexion client

# Client Windows/macOS : OpenVPN Connect ou OpenVPN GUI
# Importer le fichier .ovpn → Connect

# Client Linux
sudo openvpn --config max-portable.ovpn

9Logs et troubleshoot

sudo journalctl -u openvpn-server@server -f
sudo tail -f /var/log/openvpn/openvpn.log
SÉCURITÉ — Le fichier .ovpn contient la clé privée client. À transmettre chiffré (7-Zip AES256 + mot de passe séparé). Ne jamais l'envoyer par mail en clair ni le stocker dans un cloud personnel.

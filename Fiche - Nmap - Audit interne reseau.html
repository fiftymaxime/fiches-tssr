AUDIT · RECONNAISSANCE

Nmap — Audit interne réseau

Objectif : cartographier le réseau (hôtes actifs, ports ouverts, services, versions) dans un cadre autorisé.

1Installer Nmap

sudo apt install nmap -y

2Découverte des hôtes actifs (ping sweep)

sudo nmap -sn 192.168.1.0/24

-sn : pas de scan de port, juste "qui répond".

3Scan rapide des 1000 ports TCP les plus courants

sudo nmap 192.168.1.0/24

4Scan complet — tous les ports TCP (65535)

sudo nmap -p- 192.168.1.10

5Détection versions + OS

sudo nmap -sV -O 192.168.1.10

-sV : version des services / -O : OS fingerprinting.

6Scan agressif (tout-en-un)

sudo nmap -A 192.168.1.10

Équivalent à -sV -O -sC --traceroute. Verbeux mais complet.

7Scan UDP (lent mais essentiel : DNS, SNMP, NTP)

sudo nmap -sU --top-ports 100 192.168.1.10

8Scripts NSE — détection de vulnérabilités

# Scripts "safe" uniquement (recommandé en interne)
sudo nmap --script safe 192.168.1.10

# Détection vuln connues (peut être intrusif)
sudo nmap --script vuln 192.168.1.10

# Un script précis, ex : SMB shares
sudo nmap --script smb-enum-shares -p 445 192.168.1.10

9Sauvegarder les résultats (3 formats)

sudo nmap -A 192.168.1.0/24 -oA audit-$(date +%F)
# Génère : audit-2026-07-25.nmap / .gnmap / .xml

10Post-traitement en HTML lisible

sudo apt install xsltproc -y
xsltproc audit-2026-07-25.xml -o audit-2026-07-25.html
firefox audit-2026-07-25.html &

11Cibles depuis un fichier

cat > targets.txt <<EOF
192.168.1.10
192.168.1.20
srv-web.monlab.local
EOF

sudo nmap -iL targets.txt -sV

12Timing (contrôle de la vitesse)

-T0 : paranoïaque (IDS-safe, très lent)
-T1 : sneaky
-T2 : polite       # peu de bande passante
-T3 : normal (par défaut)
-T4 : aggressive   # réseau local rapide
-T5 : insane       # peut manquer des résultats
AUTORISATION — Ne jamais scanner un réseau sans autorisation écrite du responsable. Un scan actif = intrusion aux yeux de la loi. Documenter la mission (RACI, dates, périmètre).

VIRTUALISATION · PROXMOX

Proxmox VE — Install, VM, snapshot, backup

1Installer Proxmox depuis l'ISO

Télécharger : https://www.proxmox.com/en/downloads
Créer une clé USB bootable (Rufus / Ventoy)
Boot → suivre l'assistant :
  Target disk : SSD dédié système
  Country/Timezone/Keyboard
  Root password + email
  Management : hostname (pve01.monlab.local), IP, gateway, DNS
Reboot

2Accès web

https://IP_PROXMOX:8006
Login : root / (mot de passe défini)
Realm : PAM (Linux)

3Désactiver le repo enterprise + activer no-subscription

sudo nano /etc/apt/sources.list.d/pve-enterprise.list
# Commenter la ligne enterprise

sudo nano /etc/apt/sources.list.d/pve-no-subscription.list
deb http://download.proxmox.com/debian/pve bookworm pve-no-subscription

sudo apt update && sudo apt dist-upgrade -y

4Ajouter un pool de stockage

Datacenter → Storage → Add
  ID     : local-nfs
  Type   : NFS
  Server : 192.168.1.50
  Export : /srv/nfs/proxmox
  Content: Disk image, ISO image, Backups

5Uploader une ISO

Datacenter → pve01 → local (storage) → ISO Images → Upload
  → Sélectionner l'ISO de l'OS invité

6Créer une VM

Create VM (bouton en haut à droite)

General   : Node = pve01, VM ID = 100, Name = srv-web-01
OS        : ISO Image = debian-12.iso, Type = Linux
System    : Machine = q35, BIOS = OVMF (UEFI), Add EFI Disk ✔
Disks     : Bus = SCSI, Storage = local-nfs, Size = 40 GiB, SSD emulation ✔
CPU       : Cores = 2, Type = host
Memory    : 4096 MB
Network   : Bridge = vmbr0, Model = VirtIO
Finish    : décocher "Start after created"

Installer l'OS depuis l'ISO → à la fin, retirer l'ISO du lecteur virtuel.

7Snapshot avant intervention risquée

VM → Snapshots → Take Snapshot
  Name        : avant-maj-kernel
  Description : snapshot avant apt dist-upgrade
  Include RAM : ✔ (si VM allumée)

8Restauration d'un snapshot

VM → Snapshots → Sélectionner → Rollback

9Sauvegarde planifiée (Backup Job)

Datacenter → Backup → Add

Node        : pve01
Storage     : local-nfs
Selection   : All VMs (ou choix)
Schedule    : sat 02:00 (samedi 2h)
Mode        : Snapshot (ne pas éteindre la VM)
Compression : ZSTD
Retention   : keep-last=7, keep-weekly=4, keep-monthly=3
Notification: email

10Restauration d'une sauvegarde

Storage local-nfs → Backups → sélectionner la sauvegarde → Restore
  Target VMID : 200 (nouveau, ou écraser 100)

11CLI utile

qm list                     # liste des VM
qm start 100
qm stop 100
qm snapshot 100 nom-du-snap
vzdump 100 --storage local-nfs --mode snapshot
pvesh get /nodes            # API en CLI
SANS TPM VIRTUEL — Pour installer une VM Windows 11, il faut ajouter un TPM virtuel (Add TPM State) et une machine q35 + BIOS OVMF (UEFI). Sinon l'installeur bloque au check TPM.

CONTAINERS · DOCKER

Docker — Bases opérationnelles

1Installer Docker (Debian/Ubuntu)

# Script officiel Docker
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
# Se déconnecter/reconnecter pour appliquer

docker --version
docker run hello-world

2Vocabulaire minimum

Image      : modèle immuable (ex : nginx:latest)
Conteneur  : instance en cours d'exécution d'une image
Volume     : stockage persistant, survit à la suppression du conteneur
Réseau     : bridge, host, macvlan...
Registry   : dépôt d'images (Docker Hub, Harbor, GHCR)

3Lancer un premier conteneur

docker run -d --name web -p 8080:80 nginx:latest
# -d : détaché  |  -p 8080:80 : port hôte → port conteneur

curl http://localhost:8080

4Commandes essentielles

docker ps                          # conteneurs en cours
docker ps -a                       # tous, y compris arrêtés
docker logs -f web
docker exec -it web bash            # shell dans le conteneur
docker stop web
docker start web
docker restart web
docker rm -f web
docker images
docker rmi nginx:latest
docker inspect web

5Volumes (persistance)

# Named volume (géré par Docker)
docker volume create pgdata
docker run -d --name db -v pgdata:/var/lib/postgresql/data postgres:16

# Bind mount (dossier hôte)
docker run -d --name web -v /home/user/site:/usr/share/nginx/html:ro nginx

6Réseaux

docker network create appnet
docker run -d --name db --network appnet postgres:16
docker run -d --name api --network appnet monapi
# api peut joindre db par le nom "db"

7docker-compose (stack multi-conteneurs)

nano docker-compose.yml
services:
  web:
    image: nginx:latest
    ports: ["8080:80"]
    volumes: ["./site:/usr/share/nginx/html:ro"]
    restart: unless-stopped

  db:
    image: postgres:16
    environment:
      POSTGRES_PASSWORD: MotDePasse
    volumes: ["pgdata:/var/lib/postgresql/data"]
    restart: unless-stopped

volumes:
  pgdata:
docker compose up -d
docker compose ps
docker compose logs -f
docker compose down       # stop + supprime les conteneurs
docker compose down -v    # + supprime les volumes (DESTRUCTIF)

8Construire une image (Dockerfile)

nano Dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["python", "app.py"]
docker build -t monapp:1.0 .
docker run -d --name app -p 8000:8000 monapp:1.0

9Push vers un registry

docker login
docker tag monapp:1.0 mondockerhub/monapp:1.0
docker push mondockerhub/monapp:1.0

10Nettoyage (à faire régulièrement)

docker system df                 # voir l'espace utilisé
docker container prune            # supprime conteneurs arrêtés
docker image prune -a            # supprime images inutilisées
docker volume prune              # volumes orphelins
docker system prune -a --volumes # TOUT (attention !)
SÉCURITÉ — Ne jamais exposer le socket Docker (/var/run/docker.sock) à l'extérieur ou dans un conteneur non-fiable = équivalent à un accès root sur l'hôte. Éviter docker run --privileged sauf cas très précis.

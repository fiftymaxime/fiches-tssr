LINUX · PARTAGE FICHIERS

Partage NFS sur Debian

Côté serveur

1Installer le serveur NFS

sudo apt update
sudo apt install nfs-kernel-server -y

2Créer le dossier à partager

sudo mkdir -p /srv/nfs/shared
sudo chown nobody:nogroup /srv/nfs/shared
sudo chmod 777 /srv/nfs/shared

3Déclarer le partage dans /etc/exports

sudo nano /etc/exports

Ajouter une ligne (adapter le sous-réseau autorisé) :

/srv/nfs/shared 192.168.1.0/24(rw,sync,no_subtree_check)

Options usuelles :

  • rw — lecture/écriture
  • sync — écriture confirmée avant retour
  • no_subtree_check — meilleures performances
  • root_squash (par défaut) — un root client devient nobody sur le serveur

4Appliquer et redémarrer

sudo exportfs -arv
sudo systemctl restart nfs-kernel-server
sudo systemctl enable nfs-kernel-server
sudo systemctl status nfs-kernel-server

5Ouvrir le pare-feu

sudo ufw allow from 192.168.1.0/24 to any port nfs

Côté client Linux

6Installer les outils NFS

sudo apt install nfs-common -y

7Monter le partage manuellement

sudo mkdir -p /mnt/nfs
sudo mount IP_SERVEUR:/srv/nfs/shared /mnt/nfs

8Monter automatiquement au démarrage

sudo nano /etc/fstab

Ajouter à la fin :

IP_SERVEUR:/srv/nfs/shared  /mnt/nfs  nfs  defaults  0  0

Puis tester :

sudo mount -a

9Vérifier

# Liste des partages exportés par le serveur
showmount -e IP_SERVEUR

# Vérifier que le montage est bien actif
df -h | grep nfs
ATTENTION — Ne jamais utiliser no_root_squash sur un partage exposé : un attaquant root sur le client obtiendrait les droits root sur les fichiers du serveur.

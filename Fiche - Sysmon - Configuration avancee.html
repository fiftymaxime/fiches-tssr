WINDOWS · DÉTECTION SOC

Sysmon — Journalisation avancée Windows

Sysmon (Sysinternals) enrichit massivement les événements Windows pour la détection : création de processus, connexions réseau, modifications registre, hash de fichiers, etc.

1Télécharger Sysmon

Invoke-WebRequest -Uri https://download.sysinternals.com/files/Sysmon.zip `
  -OutFile C:\Temp\Sysmon.zip
Expand-Archive C:\Temp\Sysmon.zip -DestinationPath C:\Temp\Sysmon

2Télécharger une config de référence

# SwiftOnSecurity - config équilibrée, très utilisée en entreprise
Invoke-WebRequest `
  -Uri https://raw.githubusercontent.com/SwiftOnSecurity/sysmon-config/master/sysmonconfig-export.xml `
  -OutFile C:\Temp\Sysmon\sysmonconfig.xml

# Alternative encore plus complète : Olaf Hartong (modulaire)
# https://github.com/olafhartong/sysmon-modular

3Installer avec la config

cd C:\Temp\Sysmon
.\Sysmon64.exe -accepteula -i C:\Temp\Sysmon\sysmonconfig.xml

4Vérifier le service

Get-Service Sysmon64
.\Sysmon64.exe -c        # voir la config chargée

5Consulter les événements

Observateur d'événements → Journaux des applications et des services
  → Microsoft → Windows → Sysmon → Operational

# En PowerShell - derniers processus créés (EventID 1)
Get-WinEvent -LogName "Microsoft-Windows-Sysmon/Operational" `
  -FilterXPath "*[System[EventID=1]]" -MaxEvents 20 |
  Select-Object TimeCreated,
    @{n='Image';e={$_.Properties[4].Value}},
    @{n='CommandLine';e={$_.Properties[10].Value}}

6Mettre à jour la config sans réinstaller

.\Sysmon64.exe -c C:\Temp\Sysmon\sysmonconfig.xml

7Événements clés à surveiller

EventID 1  : Process Creation             # démarrage d'un processus
EventID 3  : Network Connection            # connexion réseau sortante
EventID 7  : Image Loaded (DLL)            # DLL chargée dans un process
EventID 10 : Process Access                # ex : Mimikatz ouvre LSASS
EventID 11 : File Created
EventID 12/13/14 : Registry
EventID 22 : DNS Query
EventID 25 : Process Tampering             # process hollowing

8Forwarder vers un SIEM (Wazuh/ELK)

# Wazuh - ajouter dans ossec.conf de l'agent
<localfile>
  <location>Microsoft-Windows-Sysmon/Operational</location>
  <log_format>eventchannel</log_format>
</localfile>

# Winlogbeat (ELK) - winlogbeat.yml
winlogbeat.event_logs:
  - name: Microsoft-Windows-Sysmon/Operational

9Désinstaller

.\Sysmon64.exe -u force
VOLUME DE LOGS — Une config Sysmon non filtrée peut générer plusieurs Go/jour par poste. Toujours partir d'une config maintenue (SwiftOnSecurity/Hartong) plutôt que de la config par défaut.

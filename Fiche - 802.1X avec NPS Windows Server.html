WINDOWS SERVER · SÉCURITÉ RÉSEAU

802.1X — Authentification réseau avec NPS

Contexte : les postes doivent s'authentifier avant d'obtenir un accès sur le port du switch. NPS = serveur RADIUS Microsoft.

Sur le serveur Windows (rôle NPS)

1Installer le rôle NPS

Install-WindowsFeature NPAS -IncludeManagementTools

2Enregistrer NPS dans l'AD

netsh nps add registeredserver

3Ajouter le switch comme client RADIUS

Console NPS (nps.msc) → Clients et serveurs RADIUS → Clients RADIUS → Nouveau
  Nom convivial     : SW-CORE-01
  Adresse           : 192.168.1.2
  Secret partagé    : (générer chaîne aléatoire longue)

4Créer une stratégie de demande de connexion

Console NPS → Stratégies → Stratégies de demande de connexion → Nouveau
  Nom : 802.1X-Requests
  Type de serveur d'accès réseau : Non spécifié
  Condition : NAS Port Type = Ethernet (15)
  Authentifier les demandes sur ce serveur

5Créer la stratégie réseau (autorisation)

Console NPS → Stratégies → Stratégies réseau → Nouveau
  Nom : 802.1X-Autorises

Conditions :
  - Groupes Windows : GG_Ordinateurs_Domaine
  - NAS Port Type   : Ethernet

Autorisation : Accès accordé

Méthode d'authentification :
  ✔ Microsoft: Protected EAP (PEAP)
     - Certificat serveur : (certificat de l'AC interne)
     - MSCHAPv2

Paramètres :
  RADIUS Standard → Tunnel-Type = VLAN
  Tunnel-Medium-Type = 802
  Tunnel-Private-Group-ID = 10   # VLAN affecté si succès

Sur le switch (Cisco)

6Configuration RADIUS + AAA

enable
configure terminal

aaa new-model
radius-server host 192.168.1.10 auth-port 1812 acct-port 1813 key SecretPartage
aaa authentication dot1x default group radius
aaa authorization network default group radius
dot1x system-auth-control

7Activer 802.1X sur les ports d'accès

interface range fastEthernet 0/1 - 24
  switchport mode access
  authentication port-control auto
  dot1x pae authenticator
  authentication host-mode multi-auth
  spanning-tree portfast
end
write memory

Côté poste client Windows

8Activer le service Wired AutoConfig

Set-Service -Name dot3svc -StartupType Automatic
Start-Service dot3svc

Via GUI : Panneau de configuration → Centre réseau → Modifier les paramètres de la carte → Propriétés → onglet Authentification → cocher Activer l'authentification IEEE 802.1X → Méthode : PEAP.

9Test et troubleshoot

# Sur le switch - voir l'état de l'authentification par port
show authentication sessions
show dot1x all summary
show dot1x interface fa0/1 details

# Sur le serveur NPS - Observateur d'événements → Journaux personnalisés → Rôles serveur → NPS
Get-WinEvent -LogName Security | Where-Object {$_.Id -eq 6272 -or $_.Id -eq 6273} | Select -First 10
PIÈGE FRÉQUENT — Le certificat serveur NPS doit être reconnu par le client. Si l'AC interne n'est pas déployée par GPO sur les postes, l'auth PEAP échoue. Vérifier : Get-ChildItem Cert:\LocalMachine\Root.

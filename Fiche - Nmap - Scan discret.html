AUDIT · ÉVASION IDS

Nmap — Scan discret (évasion IDS/IPS)

Techniques pour minimiser la détection par des IDS type Snort/Suricata. Utile en test d'intrusion autorisé ou en audit red team.

1SYN scan (semi-ouvert, plus discret que TCP connect)

sudo nmap -sS 192.168.1.10

Envoie SYN, reçoit SYN-ACK, envoie RST sans finaliser le handshake. Non loggé par les applications.

2Timing lent

sudo nmap -sS -T1 192.168.1.10        # sneaky
sudo nmap -sS -T0 192.168.1.10        # paranoid (très lent)

# Contrôle fin - 1 paquet toutes les 15s
sudo nmap -sS --scan-delay 15s 192.168.1.10

3Fragmentation des paquets

sudo nmap -sS -f 192.168.1.10          # fragments de 8 octets
sudo nmap -sS -ff 192.168.1.10         # fragments de 16 octets
sudo nmap -sS --mtu 24 192.168.1.10    # MTU custom (multiple de 8)

4Decoys (leurres)

# Le scan semble venir de 4 IP différentes en plus de la vraie
sudo nmap -sS -D 192.168.1.5,192.168.1.6,ME,192.168.1.8 192.168.1.10

# Decoys aléatoires (10 IP)
sudo nmap -sS -D RND:10 192.168.1.10

5Port source spécifique (contournement d'ACL)

# Certains firewalls autorisent le trafic depuis port 53 (DNS) ou 80
sudo nmap -sS --source-port 53 192.168.1.10
sudo nmap -sS -g 53 192.168.1.10        # équivalent

6Idle scan (via un hôte "zombie")

# Scan sans qu'aucun paquet ne parte de ta vraie IP
sudo nmap -sI 192.168.1.99 192.168.1.10
# 192.168.1.99 = hôte "zombie" (imprimante, IoT peu actif)

7Randomisation des cibles

sudo nmap -sS --randomize-hosts 192.168.1.0/24

8Éviter certaines phases

# Pas de découverte préalable (utile si ICMP bloqué)
sudo nmap -sS -Pn 192.168.1.10

# Pas de résolution DNS (moins de trafic vers résolveur)
sudo nmap -sS -n 192.168.1.10

9MAC spoofing

sudo nmap -sS --spoof-mac 00:11:22:33:44:55 192.168.1.10
sudo nmap -sS --spoof-mac Cisco 192.168.1.10    # adresse Cisco random

10Combinaison "furtive" complète

sudo nmap -sS -T1 -f -D RND:5 --source-port 53 -Pn -n \
  --randomize-hosts --scan-delay 5s 192.168.1.0/24
LÉGAL — Ces techniques sont légitimes uniquement dans un cadre autorisé par écrit (audit interne, pentest sur contrat). Les utiliser sans autorisation = intrusion informatique (art. 323-1 Code pénal en France, jusqu'à 5 ans de prison).
